# abemail design system

Black and white, one accent. The accent marks what needs you and nothing else.

## Logo

Bold A with a paper-plane cut through it, followed by a lowercase geometric wordmark. Lifted from the airmail mark.

| File | Use |
| --- | --- |
| `brand/logo.svg` | Lockup, black on light |
| `brand/logo-reversed.svg` | Lockup, white on dark |
| `brand/mark.svg` | A alone |
| `brand/app-icon.svg` | A on a black rounded square; favicon |

All four are generated by `node scripts/brand.mjs`, which also inlines the lockup and favicon into `public/index.html`. Edit the script, not the SVGs. The wordmark is stroke geometry, not a font, so it renders the same everywhere. To rename the app, change the glyph list in the script.

The plane facet is gray (`#c9c9c9`), never the accent. Minimum sizes: mark 16px, lockup 16px tall.

## Color

Defined in `public/tokens.css`. Components use the semantic tokens.

| Token | Value | Use |
| --- | --- | --- |
| `--black` | `#111111` | Text, primary buttons, active nav, borders that matter |
| `--white` | `#ffffff` | Background |
| `--gray-600` | `#5f5f5f` | Secondary text (6.4:1 on white) |
| `--gray-400` | `#9a9a9a` | Input borders, dashed outlines |
| `--gray-200` | `#dcdcdc` | Dividers |
| `--gray-100` | `#eeeeee` | Hover, muted fills |
| `--gray-50` | `#f7f7f7` | Row hover, code background |
| `--accent` | `#ff4a1c` | Needs you, errors, setup warnings, focus ring |

Accent rules: fills, dots, bars and rings only. Text on accent is black (6.2:1). Never use accent for text on white.

## Type

System UI font (`Segoe UI Variable Text`, `Segoe UI`, `system-ui`). Mono (`Cascadia Mono`, `Consolas`) for message bodies.

Sizes: 11 (meta, badges), 12 (secondary, forms), 14 (body), 18 (page and dialog titles), 24 (reserved). Weights: 400 and 600, 700 for titles. Numbers use tabular figures.

## Shape and layout

- Radius 4px on controls and badges, 8px on panels and dialogs.
- No shadows and no gradients.
- Sidebar is 200px. The page header is 60px and holds the page title, mode and Refresh.
- Messages are dense rows: sender, subject over preview, badge and time. No cards or avatars.
- Below 760px the sidebar becomes a top bar with scrolling tabs, and rows stack.

## Components

- **Buttons:** primary is black fill; default is white with a black border; quiet has no border. One primary per area.
- **Nav:** text only. Active is a black fill.
- **Banner:** black border with a 4px accent left edge. Used for setup problems and errors.
- **Notice:** gray border; errors get the accent edge.
- **Inputs:** gray-400 border, black on hover, accent focus ring.

## Copy

Say what it is or what happened, nothing else. Labels are nouns ("Queue", "Rules"), buttons are verbs ("Check now", "Save"). No taglines, no eyebrows, no reassurance beyond stating facts ("Gmail unchanged.").
